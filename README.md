# Mobile Sales Dashboard using Power BI

## Project Overview
An interactive Mobile Sales Dashboard developed using Microsoft Power BI to analyze mobile sales performance and business trends.

## Key Features
- Total Sales KPI
- Total Quantity KPI
- Total Transactions KPI
- Average Sales KPI
- Monthly sales filtering using a slicer
- Interactive charts and visualizations

## Tools Used
- Microsoft Power BI
- Data Analysis
- Data Visualization
- Dashboard Development

## Project Objective
To analyze mobile sales data, monitor key performance indicators, and present business insights through an interactive dashboard.
